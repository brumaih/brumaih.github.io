Personal software · Under development

A personal archive for coding conversations.

Session Transcript Pipeline is a desktop utility being developed to preserve Claude Code and Codex session transcripts in the account owner's personal Google Drive.

What it is designed to do

The utility reads local session records, keeps the original records, and creates readable Markdown copies with an index. The owner initiates a refresh from their computer.

The planned archive retains conversations without automatic expiry and supports retrieval and text search.

Why it connects to Google

The owner signs in to authorize the utility to create and manage its archive files in their Google Drive. The application requests the Google Drive file permission for files created or explicitly authorized for use with the app.

This is a personal tool, with no public registration or hosted transcript service.

Application information

This site provides the application's description, privacy policy, and terms of use. Development and the Google Drive archive migration are still in progress.
